How it works

Simple. Autonomous. Instant.

DataVend is a fully autonomous AI agent. No logins, no API keys for users — just connect your Freighter wallet, pay and get data.

01 🔗

Connect Freighter Wallet

Connect your Stellar Freighter wallet extension. This is how you authorize the $0.01 USDC micropayment via x402.

02 🔍

Enter a Wallet Address

Paste any Stellar mainnet wallet address into the analyzer. DataVend accepts any valid Stellar public key.

03 💳

Pay via x402

Your Freighter wallet signs a $0.01 USDC micropayment using the x402 protocol. The payment IS the credential — no account needed.

04 📊

Get AI Insights

Receive token balances, transaction history, portfolio chart, and an AI-written wallet summary powered by Claude.
